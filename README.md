# GODPEED-HQ-PLATFORM

GODSPEED HQ is the unified operating platform for GODSPEED Team, combining network-marketing operations (NeoLife), freelancing/digital-services, office administration, learning, financial accountability, academic tracking, leadership development, and performance analytics.

## Core Features
- **Authoritative Profile**: 5 Management Questions continuous profiling.
- **Sponsor Genealogy Tree**: Non-cyclic hierarchy with automated QPV baseline calculation & rank qualification alerts.
- **GPS-Geofenced, Facial-Verified Attendance**: Layered verification (QR Code + Face Match + Liveness + PostGIS Geofence).
- **NeoLife PV & Carriage Workflow**: Order tracking state machine (`pv_submitted` -> `ready_for_pickup` -> `carriage_uploaded` -> `approved`).
- **Freelancing & 10/20/70 Ledger**: Automated split calculation (10% Office Due, 20% Personal Savings, 70% Business Reinvestment Fund).
- **Leadership Health Engine**: Health states (Green, Amber, Red) & risk signal detection.
- **Hierarchical Chat & Notice Board**: Role-monitored channels with privacy disclosure and Community forum.

## Database
- PostgreSQL + PostGIS extension schema located in [`supabase/schema.sql`](supabase/schema.sql).
